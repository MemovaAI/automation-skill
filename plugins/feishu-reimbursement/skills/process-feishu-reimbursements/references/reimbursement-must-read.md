# 报销必读

本文件是自动化报销的费用合规准入规则。面向员工的完整版本与本文件保持一致；处理任务时以下规则优先于“尽快提交”的操作目标。

## 核心原则

1. 仅处理真实、合理、与公司经营相关的费用。
2. 报销申请用于员工已经垫付的费用；公司直接向供应商、员工或其他收款方付款时使用付款申请。
3. 发票及其他外部凭证必须与实际销售方、购买方、商品或服务、金额及交易背景一致。
4. 禁止替票：不得用其他交易、商户或费用类别的发票顶替真实支出，也不得要求改变品名或金额。
5. 无票不等于自动拒绝，但必须如实标记为“无票待财务复核”，不得表现成有票支出。
6. 会计入账、企业所得税税前扣除、增值税进项抵扣和政府补贴认定是不同判断，自动化流程不得代替财务或审计作结论。

## 报销申请必交资料

每笔员工报销必须具备以下三项，核齐后才能准备和提交飞书表单。

1. 发票原件。无票或特殊凭证仍须走原有财务认可流程。
2. 支付记录。须能核对已支付状态、金额、日期、收款方或订单对应关系。
3. 产品使用截图。可使用产品页面、订单、订阅套餐、使用记录或服务/行程/寄送页面，须能对应本笔费用。交通、餐饮等费用使用相应服务截图和业务事由。

逐笔核对三项材料的对应关系，缺哪项只补哪项。发票不能代替支付记录或产品使用截图，不得编造用途或截图。无票或境外特殊凭证获财务认可，仅解决发票凭证路径，其余两项仍须齐全。

产品用途从用户说明和现有材料中提取，只写入飞书事由/内容和队列附件文件名，不生成、上传或归档单独的用途说明文件。三项材料均作为附件提交和归档。截图只保留核验所需信息，提醒员工遮盖无关敏感内容。

此清单用于员工已垫付款的报销申请。付款申请按付款规则准备合同、账单等依据，尚未付款时不要求提供事后支付记录。

## 合规凭证检查

发票应满足：

- 购买方是实际承担费用的公司；
- 销售方是真实收款或履约方；
- 品名、金额、数量、日期与实际业务能够相互印证；
- 原文件完整、清晰、未裁剪、未涂改且可查验；
- 不属于已提交、审批或报销的重复凭证；
- 合同、订单、付款和服务/货物证据能够形成合理业务闭环。

如发票开错、遗漏或丢失，应由真实交易方补开、换开或重新发送电子发票。

## 无票及特殊凭证

### 自然人小额零星业务

符合当期税收政策的小额零星业务可以提交收款凭证、内部凭证和付款记录。2026年参考口径为自然人每次（日）1000元，实际处理前应采用当期政策，不得拆分交易。收款凭证至少包括公司名称、收款人姓名及身份证号码、项目、金额、日期和签字。

此类任务一律标记为“无票待财务复核”，自动化流程不得自行认定可税前扣除。

### 境外软件、API、云服务及订阅

至少需要境外平台 invoice/receipt 或账单、实际支付记录、产品使用截图和人民币换算依据；金额较大或持续订阅时补充订单/套餐、服务期间、合同或审批。产品用途只写入飞书业务字段和队列附件文件名。是否涉及代扣税费、税前扣除须交财务复核。

### 最终没有合法外部凭证

保留真实业务说明、付款记录、订单、合同和审批，标记为“无票待财务复核”。不得寻找替票，不得自动认定为补贴费用。

## 自动处理结果

每项任务在进入飞书表单前必须归入以下一种状态：

- `凭证初审通过`：材料与业务表面一致，可继续准备表单；
- `无票或特殊凭证待财务复核`：可以整理材料，但未经人工确认不得提交；
- `不合规或疑似替票`：停止处理并指出具体不一致；
- `信息不足`：停止并索取缺失的最小材料。

## 常见材料

下表是各类型的专项材料，员工报销均须同时满足上述三项必交资料；表中补充材料不能降低必交要求。

| 类型 | 必要材料 | 补充材料 |
|---|---|---|
| 办公用品、设备 | 发票、付款记录 | 订单、明细、用途 |
| 国内软件和服务 | 发票、付款记录 | 订单、服务期间、使用说明 |
| 境外订阅/API/云服务 | invoice/receipt、付款记录 | 套餐、期间、用途、换算依据 |
| 差旅交通和住宿 | 发票或合规票据 | 行程、人员、事由、审批 |
| 招待或工作餐 | 发票、付款记录 | 事由、必要的参与人员信息 |
| 外包、咨询、设计 | 发票、合同、付款依据 | 成果、验收或服务记录 |
| 自然人零星服务 | 合规收款凭证、付款记录 | 服务内容和履约证据 |

## 退回或暂停条件

- 疑似替票、虚假交易或个人费用；
- 抬头、销售方、内容或金额与业务不一致；
- 发票或认可凭证、支付记录、产品使用截图任一缺失；
- 凭证重复；
- 图片不清、裁剪、缺页或关键字段不明；
- 报销人、日期、金额或账户无法核实；
- 无票且没有业务说明和付款证据。
